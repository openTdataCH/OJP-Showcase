# GTFS RT <-> GTFS static compare tool

## Scripts

### cli_compare_latest.py
- fetch latest GTFS-RT file
- compares them against current DB which is read from catalog file  - see `gtfs_dbs_json_path` in [./config/config.yml]()
- generates ./gtfs-rt-static-compare-report/[YEAR]/[MONTH]/[DAY]/gtfs_rt_static_report-[YEAR]-[MONTH]-[DAY]-[HHMM].json file

### cli_aggregate_monthly_reports_json.py
- aggregates current or given month reports generated by `cli_compare_latest.py`
- adds/updates ./data/gtfs-rt-static-compare-report/[YEAR]/gtfs_rt_static_report-[YEAR]-[MONTH].json file
